
# ATM with GUI (C#)

A user-friendly ATM application with a graphical user interface built using C#. This project simulates ATM functionalities, allowing users to perform basic banking operations like checking balance, depositing money, and withdrawing money. The intuitive design ensures a seamless user experience.

## Features
- User authentication with a secure PIN system.
- Check account balance.
- Deposit funds into an account.
- Withdraw funds with balance validation.
- Transaction history display.
- Responsive and visually appealing GUI.

## Requirements
- **Operating System**: Windows (compatible with Windows 10 and 11)
- **Development Environment**: Visual Studio (Recommended 2019 or later)
- **Framework**: .NET Framework 4.8 or later

## Installation and Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/mohamed426/ATM-with-GUI-csharp.git
   ```
2. Open the project in Visual Studio.
3. Restore NuGet packages if necessary:
   - Go to `Tools > NuGet Package Manager > Manage NuGet Packages for Solution`.
   - Restore any missing packages.
4. Build the solution (`Ctrl + Shift + B`) to compile the project.
5. Run the application (`F5` or Start button in Visual Studio).
6. Interact with the ATM interface to simulate banking operations.
